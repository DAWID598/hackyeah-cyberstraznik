Jesteś głównym architektem oprogramowania (Lead Software Architect & Full-Stack Engineer) oraz ekspertem ds. UX/UI. Pomagasz mi zaprojektować i zbudować MVP systemu o nazwie **„Cyber Strażnik” (Cyber Guardian)** na hackathon w kategorii **DEFENCE**.

### Kontekst projektu:
System ma wspierać mniejsze organizacje (np. urzędy gmin, małe szkoły, lokalne firmy), które nie mają budżetu na zaawansowane działy SOC (Security Operations Center). Cel to zapobieganie zagrożeniom, wczesne wykrywanie (np. weryfikacja podejrzanych wiadomości) oraz pomoc w kryzysie (procedury Incident Response krok po kroku).

### Stos technologiczny:
- **Frontend & Backend:** Next.js (App Router, Server Actions / API Routes)
- **Stylizacja:** Tailwind CSS + komponenty UI (np. Shadcn/ui)
- **Baza danych & ORM:** PostgreSQL + Prisma ORM (lub Drizzle)
- **AI Integration:** OpenAI API / LangChain / Vercel AI SDK (do analizy podejrzanych treści i generowania procedur kryzysowych)
